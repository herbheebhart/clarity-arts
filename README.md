# VisionAI Studio

Create a modern AI web application called VisionAI. The design should be extremely clean, premium, responsive, and simple enough that a 10-year-old can use it without instructions. Use rounded cards, soft shadows, a light modern theme, smooth animations, and fast navigation.

Sidebar: AI Research, Image Studio, Prompt Library, Prompt Builder, Projects, Settings.

AI Research: large chat area, message input, file upload, copy response, regenerate, clear chat, chat history, new chat.

Image Studio: connected model selector, prompt box, negative prompt, aspect ratio, quality selector, generate button, gallery, download, copy prompt, save to projects.

Prompt Builder: automatically structure prompts into Subject, Style, Lighting, Camera, Background, Colors, Composition, Extra Details. Include one-click copy.

Prompt Library: categorized templates (Product Photography, YouTube Thumbnails, Movie Posters, Children's Story Illustrations, Realistic Portraits, Logos, Anime, Fantasy Art, Cinematic Scenes), search, favorites.

Projects: save research chats, prompts, images.

Settings: theme switch, language selector, connected AI providers, API key management.

General Requirements: Mobile friendly, fast loading, beautiful typography, smooth transitions, large clear buttons, minimal clutter, professional dashboard, easy navigation. All listed tools must work reliably with no errors and properly functioning API integration.
